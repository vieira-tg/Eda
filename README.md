# Eda — workspace do EdaMetricas

Esta pasta é o workspace de desenvolvimento. O projeto em si — o que vai
para o GitHub — é a subpasta **[EdaMetricas/](EdaMetricas/README.md)**:

```
Eda/
├── .venv/          # ambiente local (ignorado pelo git)
├── EdaMetricas/    # O APP — repositório público
│   ├── README.md   # documentação principal
│   ├── LICENSE     # MIT
│   └── ...
└── prompt_EdaMetricas.md   # documento interno de especificação original
```

Para rodar o app localmente a partir daqui:

```powershell
.venv\Scripts\python.exe EdaMetricas\main.py
```
